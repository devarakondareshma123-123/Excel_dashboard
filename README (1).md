## 🚀 Features

### 🎛️ Interactive Filters (Slicers)
- **Date Timeline Slicer** — Filter data by month/year (2020 timeline view)
- **Place Slicer** — Filter by 6 cities: Bapatla, Chirala, Guntur, Ongole, Tenali, Vijayawada
- **Product Slicer** — Filter by 6 categories: 4K LED TVs, Furniture, Laptops, LED TVs, Mobiles, Speakers

### 📦 KPI Summary Cards
| Metric | Value |
|---|---|
| 💰 Total Amount | ₹ 1,18,73,1893 |
| 🛒 Total Sales | 278 Transactions |

### 📈 Visualizations
- **Sales by Months** — Line chart tracking monthly revenue trends (Jan – Dec)
- **Sales by Places** — Bar chart comparing city-wise revenue performance
- **Sales of Products** — Horizontal bar chart with percentage contribution per product

## 🗂️ Workbook Structure

| Sheet Name | Description |
|---|---|
| `Master Data` | Raw sales data used for all analysis |
| `DashBoard` | Main interactive dashboard view |
| `products` | Product-wise data and details |
| `Salesmans` | Salesperson-wise data |
| `About` | Project information page |
| `Pivot Tables` | Backend pivot tables powering the dashboard |

## 📁 How to Use

1. **Clone or Download** this repository
2. Open the file `Microsoft Excel Worksheet (.xlsx)` in Microsoft Excel
3. Navigate using the buttons on the left: **Dashboard**, **Products**, **Salesman**, **About**
4. Use the **Date**, **Place**, and **Products** slicers to filter data dynamically
5. All charts and KPI cards will update automatically based on your selection
